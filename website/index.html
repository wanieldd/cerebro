Why Cerebro?

💬

Streaming Chat

Real-time SSE streaming with stop generation, edit & resubmit, and regenerate responses.

🛠️

Built-in Tools

Web search, Python execution, file operations, terminal, memory, and customizable tools.

🧠

Auto-Memory

The AI remembers facts about you across conversations. View and manage memories.

🔑

Bring Your Own Key

Use any OpenRouter-compatible model. Switch between text and vision models anytime.

📁

File Support

Paste images, drag & drop files, upload documents. The AI reads and processes them.

🌙

Dark Theme

Pale dark blue design with adjustable font size, compact mode, and responsive layout.

📦

One-Command Install

Single curl command to install. Built-in update script. Docker support.

📤

Export & Share

Export conversations as JSON or Markdown. System prompt presets. Conversation folders.

How to Install

🐍 One-Command Install

curl -fsSL https://raw.githubusercontent.com/wanieldd/cerebro/main/install.sh | bash

Requires git, python3, node/npm.

🐳 Docker

docker build -t cerebro . && docker run -p 3333:3333 cerebro

📦 Manual Setup

1. git clone https://github.com/wanieldd/cerebro.git
2. cd cerebro/backend && uv sync
3. cd ../frontend && npm install && npm run build
4. cd ../backend && uv run uvicorn main:app --host 0.0.0.0 --port 3333
5. Open http://localhost:3333
